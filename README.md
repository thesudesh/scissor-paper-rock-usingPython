# Rock-Paper-Scissors Game

This is a simple graphical implementation of the classic Rock-Paper-Scissors game using Python's `tkinter` library for the GUI.

## Features

- Play Rock, Paper, Scissors against the computer.
- Scoreboard to keep track of wins and losses.
- Simple, intuitive GUI.

## Requirements

- Python 3.12
- Tkinter (comes with Python standard library)

## Installation and Setup

 **Clone the repository**

   ```
   git clone https://github.com/your-username/rock-paper-scissors-tkinter.git
   cd rock-paper-scissors-tkinter
   ```
## Set up a virtual environment (optional but recommended)

### Create a virtual environment:

```
python3 -m venv env
source env/bin/activate  # On Windows use `env\Scripts\activate`
```

### Run the Game:
```
python project.py
```

## How to Play

1. Select one of the three buttons: **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly select one as well.
3. The result (win, lose, or tie) will be displayed, and the score will be updated.
4. You can quit the game by pressing the **Quit** button.

## Notes

- The `images/` folder contains the images used in the game.
- If you're having trouble loading the images, ensure that all image files are in `.png` format and correctly located in the `images` folder.
